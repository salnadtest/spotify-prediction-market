# Security Policy

## Reporting a vulnerability

If you believe you’ve found a security issue, please **do not** open a public GitHub issue.

Instead, report it privately by emailing the repository owner (or, if email is not available, by opening a GitHub Security Advisory if enabled).

In your report, include:

- a description of the issue and impact
- steps to reproduce (proof of concept if possible)
- affected versions/commits (if known)

## Scope (current)

This repository is currently documentation-only. As code is added, this policy should be expanded to cover:

- disclosure timelines
- supported versions
- patch and release process
